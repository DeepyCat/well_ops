# API

**Application Programming Interface** – rozhraní mezi výpočetním systémem (nebo knihovnou) a aplikací. Sada funkcí a pravidel, které může program využívat pro svou práci, aniž by musel znát implementaci.

---

## Podrobně

### K čemu slouží

Program nemusí sám řešit nízkoúrovňové detaily (jak přesně vykreslit okno, jak zapsat na disk) – zavolá funkci z API operačního systému nebo knihovny a ten to udělá za něj.

### Co API operačního systému nabízí

- Dialogová okna a prvky grafického rozhraní
- Funkce OS (souborový systém, paměť…)
- Ovladače zařízení
- Rozhraní časovače

### Příklad z webu

**[[REST]]** API – standardizovaný způsob, jak aplikace komunikují přes [[HTTP]].
