# GUI

**Graphical User Interface** – grafické uživatelské rozhraní. Uživatel ovládá počítač pomocí oken, ikon, myši a dotyku, ne psaním příkazů.

---

## Podrobně

### GUI vs. CLI

| | GUI | [[CLI]] |
| :-- | :-- | :-- |
| Ovládání | myš/dotyk, ikony, okna | psaní příkazů |
| Snadnost pro začátečníky | vysoká | nízká |
| Rychlost pro pokročilé/automatizaci | nižší | vyšší |
| Náročnost na zdroje | vyšší | nižší |

### Příklady

Windows Explorer, GNOME/KDE na Linuxu, macOS Finder.
