Verze: 2026-10-17  |  Ve vzorovém postupu je číslo pracoviště 200 a příjmení novak. Vy všude dosaďte číslo svého pracoviště (192.168.N.x) a své příjmení (prijmeni.cyberschool.internal).

Ověření funkčnosti tohoto modulu probíhá v kooperaci mezi serverem SRV1-DC a klientskou stanicí PC1-WIN.

1. Role je nainstalovaná a autorizovaná v Active Directory (SRV1-DC)

V Server Manageru na Dashboardu vidíte roli DHCP zelenou, bez chyb a varování. V konzoli DHCP Manager (dhcpmgmt.msc) je u serveru viditelná zelená značka (autorizováno v AD), nikoliv červená šipka dolů.

PowerShell (Spustit na SRV1-DC) 
Get-WindowsFeature -Name DHCP, RSAT-DHCP | Select-Object Name, InstallState
Get-Service -Name DHCPServer | Select-Object Name, Status, StartType
Get-DhcpServerInDC | Select-Object DnsName, IPAddress
Očekávaný výstup: 
Name      InstallState
----      ------------
DHCP         Installed
RSAT-DHCP    Installed

Name       Status  StartType
----       ------  ---------
DHCPServer Running Automatic

DnsName                                 IPAddress
-------                                 ---------
SRV1-DC.<prijmeni>.cyberschool.internal 192.168.N.10

2. DHCP Scope je aktivní a pokrývá správný rozsah (SRV1-DC)

V konzoli DHCP existuje obor s názvem [192.168.N.0] Ucebna. Ikona oboru je zelená (aktivní), nikoliv červená.

PowerShell (Spustit na SRV1-DC) 
Get-DhcpServerv4Scope | Select-Object ScopeId, Name, StartRange, EndRange, State
Očekávaný výstup: 
ScopeId       Name   StartRange       EndRange         State
-------       ----   ----------       --------         -----
192.168.N.0   Ucebna 192.168.N.100    192.168.N.200    Active

3. Síťové volby (Scope Options) jsou kompletní (SRV1-DC)

V podsložce Scope Options jsou nakonfigurovány všechny povinné parametry pro klientské počítače:

PowerShell (Spustit na SRV1-DC) 
Get-DhcpServerv4OptionValue -ScopeId "192.168.N.0" | Select-Object OptionId, Name, Value
Očekávaný výstup: 
OptionId Name            Value
-------- ----            -----
      51 Lease           {691200}
      15 DNS Domain Name {<prijmeni>.cyberschool.internal}
       3 Router          {192.168.N.1}
       6 DNS Servers     {192.168.N.10}

Poznámka: Option 51 Lease (691200 sekund = 8 dní) je automatická výchozí doba zapůjčení ve Windows Server DHCP a je naprosto v pořádku.

4. Klient PC1-WIN dostane adresu automaticky (PC1-WIN)

Na klientské stanici PC1-WIN je rozhraní Ethernet1 (NIC 2) nastaveno na automatické získávání. Příkaz ipconfig /all nebo PowerShell ukazuje přidělenou IP adresu ze scope 192.168.N.100–.200, masku 255.255.255.0, bránu 192.168.N.1 a DNS 192.168.N.10:

PowerShell (Spustit na PC1-WIN) 
Get-NetIPAddress -InterfaceAlias Ethernet1 -AddressFamily IPv4 | Select-Object IPAddress, PrefixLength, PrefixOrigin
Get-NetIPConfiguration -InterfaceAlias Ethernet1 | Select-Object -ExpandProperty IPv4DefaultGateway
Get-DnsClientServerAddress -InterfaceAlias Ethernet1 -AddressFamily IPv4 | Select-Object ServerAddresses
Očekávaný výstup: 
IPAddress        PrefixLength PrefixOrigin
---------        ------------ ------------
192.168.N.100              24 Dhcp

NextHop: 192.168.N.1
ServerAddresses: {192.168.N.10}

5. Zápůjčka je evidována bez konfliktů (SRV1-DC)

V konzoli DHCP na SRV1-DC v sekci Address Leases je evidována právě jedna aktivní zápůjčka pro PC1-WIN bez duplicit:

PowerShell (Spustit na SRV1-DC) 
Get-DhcpServerv4Lease -ScopeId "192.168.N.0" | Select-Object IPAddress, HostName, ClientId, AddressState
Očekávaný výstup: 
IPAddress        HostName AddressState
---------        -------- ------------
192.168.N.100    PC1-WIN  Active

6. Obnovení adresy a síťová konektivita fungují (PC1-WIN)

Příkazy ipconfig /release a ipconfig /renew proběhnou bez chyb a klient znovu obdrží platnou adresu. Následně funguje komunikace na bránu, server i překlad DNS jména:

PowerShell (Spustit na PC1-WIN) 
# 1. Test uvolnění a obnovení zápůjčky:
ipconfig /release Ethernet1
ipconfig /renew Ethernet1

# 2. Test konektivity na SRV1-DC:
Test-NetConnection -ComputerName "192.168.N.10" -InformationLevel Detailed

# 3. Test překladu doménového jména přes DNS:
Resolve-DnsName -Name "srv1-dc.<prijmeni>.cyberschool.internal"
Očekávaný výstup: 
PingSucceeded : True

Name                                           IP4Address
----                                           ----------
srv1-dc.<prijmeni>.cyberschool.internal        192.168.N.10
