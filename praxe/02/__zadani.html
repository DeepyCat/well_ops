Kontext (proč to děláme)

Paní učitelka Nováková má dost přihlašování na "univerzální" lokální účty typu ucitel/ucitel, které zná celá škola. Chce, aby každý žák a učitel měl svůj vlastní účet, který funguje na libovolném počítači ve škole. To je přesně to, co řeší Active Directory Domain Services (AD DS).

Předpoklad: server je připravený (Modul 01 — Příprava VM)

Tento modul předpokládá, že server SRV1-DC už prošel přípravným modulem: má nainstalovaný Windows Server 2025 Datacenter (Desktop Experience), hostname SRV1-DC, statickou IP adresu 192.168.X.10/24 na rozhraní Ethernet1, funkční účet Administrator s heslem Pa55w.rd a hotovou lokalizaci. Pokud jste Modul 01 ještě nedokončili, vraťte se k němu nejprve.

Cílový stav: Povýšení na řadič domény

Server SRV1-DC bude mít nainstalovanou roli Active Directory Domain Services (AD DS) a bude povýšen na řadič nového lesa a domény prijmeni.cyberschool.internal.

Parametr Hodnota na SRV1-DC Poznámka
Role serveru Active Directory Domain Services (AD DS), DNS Server Instaluje se včetně RSAT nástrojů pro správu
Název domény (FQDN) prijmeni.cyberschool.internal Vaše příjmení malými písmeny bez diakritiky (např. novak.cyberschool.internal)
NetBIOS jméno domény PRIJMENI Odvozuje se automaticky velkými písmeny (např. NOVAK)
DSRM heslo Pa55w.rd Heslo pro SafeModeAdministratorPassword (režim obnovení adresářových služeb)
FSMO role Všech 5 rolí na SRV1-DC Schema Master, Domain Naming Master, PDC Emulator, RID Master, Infrastructure Master
Global Catalog (GC) True První řadič v doméně je automaticky globálním katalogem
Přihlášení po restartu PRIJMENI\Administrator Heslo zůstává standardní Pa55w.rd
  • Doména prijmeni.cyberschool.internal existuje a SRV1-DC je jejím primárním řadičem (Domain Controller).
  • Server zároveň funguje jako integrovaný DNS server pro tuto doménu (role DNS se konfiguruje automaticky spolu s AD DS).
  • Po dokončení instalace a automatickém restartu se přihlašujete jako PRIJMENI\Administrator (nebo Administrator@prijmeni.cyberschool.internal).

Instalace a povýšení v PowerShellu

Krok 1: Instalace role AD DS s nástroji pro správu:

PowerShell (Spustit jako Administrator) 
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools

Krok 2: Povýšení na řadič domény a vytvoření nového lesa (nahraďte <prijmeni> vaším příjmením, např. novak):

PowerShell (Spustit jako Administrator) 
$DomainName = "<prijmeni>.cyberschool.internal"
$SecurePassword = ConvertTo-SecureString "Pa55w.rd" -AsPlainText -Force

Install-ADDSForest -DomainName $DomainName -SafeModeAdministratorPassword $SecurePassword -InstallDns:$true -Force:$true

Ověření nástroji

Na SRV1-DC jsou po restartu plně dostupné administrační nástroje pro správu domény:

  • Active Directory Users and Computers (ADUC) – správa uživatelů, skupin a organizačních jednotek.
  • DNS Manager – správa primární dopředné zóny prijmeni.cyberschool.internal.
  • Active Directory Administrative Center (ADAC) – moderní grafické rozhraní správy domény.
  • Active Directory Domains and Trusts – správa důvěryhodností a funkčních úrovní lesa.
