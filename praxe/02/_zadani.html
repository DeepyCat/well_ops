Kontext (proč to děláme)

Škola právě vybavila novou počítačovou učebnu patnácti počítači. Ruční nastavování IP adresy na každém z nich je zdlouhavé a náchylné na chyby (dvě stejné IP adresy = konflikt a výpadek sítě). Řešením je DHCP server (Dynamic Host Configuration Protocol), který adresy přiděluje automaticky.

Pravidlo pro pracoviště: Ve vzorovém postupu je číslo pracoviště 200 a příjmení novak. Vy všude dosaďte číslo svého pracoviště (192.168.N.x, kde N je číslo vašeho pracoviště) a své příjmení bez diakritiky (prijmeni.cyberschool.internal).

Předpoklad: hotový Modul 00 a Modul 01

Tento modul předpokládá, že server SRV1-DC už úspěšně prošel předchozími kroky: je povýšen na řadič domény prijmeni.cyberschool.internal, má statickou IP adresu 192.168.N.10/24 na interním rozhraní Ethernet1, funkční DNS server a doménového správce Administrator s heslem Pa55w.rd. Klientská stanice PC1-WIN má nainstalovaný systém Windows 11 a zapnutý interní adaptér Ethernet1 v CyLabu.

Cílový stav: Plně funkční DHCP server pro učebnu

Na konci tohoto modulu bude na serveru SRV1-DC nainstalovaná, autorizovaná a plně nakonfigurovaná role DHCP Server:

  • DHCP Scope pro klientské počítače: Pokrývá rozsah 192.168.N.100 až 192.168.N.200 v podsíti 192.168.N.0/24. Adresy .1 až .99 jsou vyhrazeny pro servery a síťové prvky s pevnou konfigurací.
  • Kompletní síťové volby (Scope Options): Klientům se automaticky předá maska, výchozí brána 192.168.N.1, DNS server 192.168.N.10 a název domény <prijmeni>.cyberschool.internal.
  • Autorizace v Active Directory: Server je autorizován v doméně, v konzoli DHCP Manageru svítí zelená značka bez varování.
  • Ověřený klient PC1-WIN: Po přepnutí adaptéru Ethernet1 na DHCP získá stanice funkční IP adresu bez jakéhokoliv ručního zásahu.
  • Evidence zápůjček bez konfliktů: V konzoli DHCP v sekci Address Leases je evidován právě jeden lease pro PC1-WIN bez duplicit.

Postup konfigurace v PowerShellu

Krok 1: Instalace role DHCP Serveru s nástroji pro správu na SRV1-DC:

PowerShell (Spustit jako Administrator na SRV1-DC) 
Install-WindowsFeature -Name DHCP -IncludeManagementTools

Krok 2: Vytvoření bezpečnostních skupin a restartování služby DHCPServer na SRV1-DC:

PowerShell (Spustit jako Administrator na SRV1-DC) 
Add-DhcpServerSecurityGroup
Restart-Service -Name DHCPServer

Krok 3: Autorizace DHCP serveru v Active Directory na SRV1-DC:

PowerShell (Spustit jako Administrator na SRV1-DC) 
$DnsName = "$env:COMPUTERNAME.$((Get-ADDomain).DNSRoot)"
$IP = "192.168.N.10"
Add-DhcpServerInDC -DnsName $DnsName -IPAddress $IP

Krok 4: Vytvoření a aktivace DHCP Scope pro učebnu na SRV1-DC:

PowerShell (Spustit jako Administrator na SRV1-DC) 
Add-DhcpServerv4Scope -Name "Ucebna" -StartRange "192.168.N.100" -EndRange "192.168.N.200" -SubnetMask "255.255.255.0" -State Active

Krok 5: Nastavení voleb Router, DNS Server a DNS Domain Name na SRV1-DC:

PowerShell (Spustit jako Administrator na SRV1-DC) 
$DomainName = (Get-ADDomain).DNSRoot
Set-DhcpServerv4OptionValue -ScopeId "192.168.N.0" -Router "192.168.N.1" -DnsServer "192.168.N.10" -DnsDomain $DomainName

Krok 6: Aktivace automatického DHCP na klientovi PC1-WIN a obnova adresy:

PowerShell (Spustit jako Administrator na PC1-WIN) 
Set-NetIPInterface -InterfaceAlias "Ethernet1" -Dhcp Enabled
Set-DnsClientServerAddress -InterfaceAlias "Ethernet1" -ResetServerAddresses
ipconfig /release Ethernet1
ipconfig /renew Ethernet1

Krok 7: Kontrola zápůjček a síťového spojení:

PowerShell (Ověření na SRV1-DC i PC1-WIN) 
# Na SRV1-DC:
Get-DhcpServerv4Lease -ScopeId "192.168.N.0" | Select-Object IPAddress, HostName, ClientId, AddressState

# Na PC1-WIN:
Test-NetConnection -ComputerName "192.168.N.10"
Resolve-DnsName -Name "srv1-dc.<prijmeni>.cyberschool.internal"

Ověření nástroji

Na serveru SRV1-DC je dostupná grafická konzole DHCP Manager (dhcpmgmt.msc):

  • Server Manager → Tools → DHCP: V kořenovém stromu je u názvu serveru zobrazena zelená značka (autorizováno v AD).
  • Scope [192.168.N.0] Ucebna → Address Pool: Definuje rozsah 192.168.N.100 až 192.168.N.200.
  • Scope Options: Zahrnuje Option 003 (Router), Option 006 (DNS Servers) a Option 015 (DNS Domain Name).
  • Address Leases: Zobrazuje aktivní zápůjčku klientského počítače PC1-WIN.
